# Docs/REVISIONES/

Carpeta del rol `revisor`. Único dueño — y, como `investigador`, `revisor` es
**read-only**: estas fichas las pega el hilo principal a partir de lo que reporta.

Vive acá: hallazgos `FIND-XX` con qué se entregó, qué criterio se incumple, evidencia
(archivo, línea o salida de comando) y severidad. Nunca una corrección: `revisor` reporta,
no arregla.

Archivos con prefijo `REV-`. Convención completa de IDs en `../IDS.md`.

¿Necesitás algo de esta carpeta desde otro rol? Dejá una propuesta en
`Docs/SUGERENCIAS/<PREFIJO>-para-revisor-<tema>.md`. No se edita directamente.
