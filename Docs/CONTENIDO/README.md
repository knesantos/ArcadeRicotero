# Docs/CONTENIDO/

Carpeta del rol `contenido`. Único dueño de acá y de `src/data/*.json` (cuyo schema
define `arquitectura`).

Vive acá: piezas `CNT-XX` con el banco de preguntas y sus distractores, criterios de
estilo y tono, y **la nota de derechos** de fragmentos de audio, tapas de Rocambole y
letras. Esa nota bloquea la publicación entera hasta que esté cerrada.

Archivos con prefijo `CNT-`. Convención completa de IDs en `../IDS.md`. `contenido` no
tiene `WebSearch` ni `WebFetch`: todo hecho verificable que necesite lo pide como ficha
`RES-XX` a `investigador`.

¿Necesitás algo de esta carpeta desde otro rol? Dejá una propuesta en
`Docs/SUGERENCIAS/<PREFIJO>-para-contenido-<tema>.md`. No se edita directamente.
