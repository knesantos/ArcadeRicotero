# Docs/ARQ/

Carpeta del rol `arquitectura`. Único dueño: nadie más escribe acá.

Vive acá: decisiones `ADR-XX` (motor de audio, vía de integración con Spotify — hoy
`ADR-01`, pendiente) con alternativas descartadas, contratos `CTR-XX` (el schema que
valida los JSON de `src/data/`), y los requisitos no funcionales (presupuesto de
precarga de audio, formato y duración de fragmento).

Archivos con prefijo `ARQ-`. Convención completa de IDs en `../IDS.md`. Estos `ADR-XX`
son distintos de los `D-XX` de `Docs/DECISIONES.md`: ver la nota al principio de ese
archivo.

¿Necesitás algo de esta carpeta desde otro rol? Dejá una propuesta en
`Docs/SUGERENCIAS/<PREFIJO>-para-arquitectura-<tema>.md`. No se edita directamente.
