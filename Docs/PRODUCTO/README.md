# Docs/PRODUCTO/

Carpeta del rol `producto`. Único dueño: nadie más escribe acá.

Vive acá: historias `US-XX` con criterio Given/When/Then, reglas de negocio `BR-XX`, el
alcance vigente de la v1, lo que queda explícitamente afuera, y el piso de ítems que cada
uno de los cuatro juegos necesita para considerarse listo.

Archivos con prefijo `PRD-`. Convención completa de IDs en `../IDS.md`.

¿Necesitás algo de esta carpeta desde otro rol? Dejá una propuesta en
`Docs/SUGERENCIAS/<PREFIJO>-para-producto-<tema>.md`. No se edita directamente.
