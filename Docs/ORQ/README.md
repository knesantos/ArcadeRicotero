# Docs/ORQ/

Carpeta del rol `orquestador`. Único dueño: nadie más escribe acá, y `orquestador` no
escribe fuera de acá — ni código de producción, ni archivos de otro rol.

Vive acá: el reporte de coherencia entre los siete roles, y los planes de ciclo
`ORQ-plan-ciclo-<n>.md` con tareas `T-XX` autocontenidas, cada una con dueño, archivos
exactos y verificación, para que cierren enteras en una ráfaga.

Archivos con prefijo `ORQ-`. Convención completa de IDs en `../IDS.md`.

¿Necesitás algo de esta carpeta desde otro rol? Dejá una propuesta en
`Docs/SUGERENCIAS/<PREFIJO>-para-orquestador-<tema>.md`. No se edita directamente.
