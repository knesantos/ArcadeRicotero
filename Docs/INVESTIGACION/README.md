# Docs/INVESTIGACION/

Carpeta del rol `investigador`. Único dueño: nadie más escribe acá — y de hecho el propio
`investigador` no escribe directamente: es **read-only**, así que estas fichas las pega
el hilo principal a partir de lo que `investigador` reporta.

Vive acá: fichas `RES-XX` con hallazgo, URL y fecha de consulta, o marcadas
explícitamente como leyenda no verificada. Discografía, cronología, obra de Rocambole,
estado real de las APIs de Spotify.

Archivos con prefijo `INV-`. Convención completa de IDs en `../IDS.md`. `investigador` es
el único rol del equipo con `WebSearch` y `WebFetch`: es la única puerta a la web.

¿Necesitás algo de esta carpeta desde otro rol? Dejá una propuesta en
`Docs/SUGERENCIAS/<PREFIJO>-para-investigador-<tema>.md`. No se edita directamente.
